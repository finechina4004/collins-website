# Printed Collins cover title

The owner asked to make COLLINS look more natural in the artwork and approved the recommended changes. The home title now uses the exact existing outlined wordmark with warmer olive ink (#485039), a restrained fractal grain alpha filter, and multiply blending that lets the underlying paper tone show through. The subtitle is moved 10 SVG units closer to COLLINS. The homepage wordmark is about 20% larger on desktop, with tighter header spacing and a lower position in the painted sky to close the gap above the villa. Narrow/short viewport rules keep navigation clear.

The new `collins-wordmark-printed.svg` preserves every letter outline in the original asset. It is an SVG/code change, not a regenerated logo. Only the homepage shows it; the original wordmark continues on inner pages. The original backyard artwork and all scene hotspot coordinates remain unchanged. Navigation stays live HTML and has no grain filter.

Validation: desktop homepage and inner-page/back navigation; 390×844 and 390×640 phone frames; 2048×1152 frame; SVG XML parse and exact path equality with original; whitespace and Wrangler dry-run. Browser frames are layout checks, not physical-device tests. No calls or messages sent.
